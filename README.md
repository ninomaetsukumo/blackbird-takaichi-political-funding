## Research boundary / 調査上の境界

This report maps publicly documented political-funding, support-organisation, donor, business, public-sector, shared-address, and vendor relationships around Sanae Takaichi-linked political organisations in Japan.

It does **not** establish a unified donor network, quid pro quo, circular funding, common hidden control, private enrichment, criminal liability, or wrongdoing merely from donations, shared addresses, public contracts, corrections, refunds, support roles, or public-program participation.

本報告は、日本における高市早苗氏関連政治団体をめぐる、公開記録上確認できる政治資金、後援組織、献金者、企業、公共部門、共通住所、業者関係を整理したものです。

献金、共通住所、政府契約、訂正、返金、後援会役職、公的事業参加のみを根拠として、単一の献金ネットワーク、対価関係、循環資金、隠れた共通支配、私的利益、刑事責任、不正行為を認定するものではありません。

## Evidence model / 証拠モデル

Project Blackbird separates:

- **Verified Fact**
- **Corroborated**
- **Reported Information**
- **Analytical Judgment**
- **Hypothesis**
- **Negative Finding**
- **Unknown / Unresolved**

Primary and official sources are preferred where available. A documented association does not imply misconduct, and absence of public evidence is not treated as evidence of concealment.
